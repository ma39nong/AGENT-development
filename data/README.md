# 数据与标注约定

原始视频和既有ROI标注保留原位置，只建立清单或生成到新目录，不覆盖源数据。
`raw/`、`derived/`、`splits/`默认不进入Git；提交schema、构建脚本和脱敏的小型例子即可。

以下为最终在线训练样本的字段方向，不是全量人工标注前置条件。当前先沿用subtask与三路视频，由API生成候选，再复核少量计数时间点，见[当前标注范围](event_annotation_requirements.md)。

最终样本按任务需要包含：

- 完整源录制标识、派生关系、窗口时间和数据版本。
- 用户目标数量、显式顺序约束，不能只包含固定两轮示范。
- 原始三路证据；使用头部局部图时附裁剪来源和源时间。
- 当前任务/执行状态、历史事件引用、待处理事件和记忆快照。
- 事件、证据、下一技能、触发/完成条件和异常分支的监督标签。
- 标注来源、人工核查状态、遮挡/不确定状态；模型伪标签不能伪装成人工真值。

成功投放与摘离分开标注；既有阶段边界不能直接当作单颗事件边界。
重复窗口/同源裁剪需关联同一事件。对于是否需要调整与提前放回，缺少示范和可执行依据时不得虚构正例。

先按源录制分组划分，再切窗口；同录制派生的全部视角、裁剪和重叠窗口必须同组。
冻结测试清单后，训练和提示词调整不得使用测试标签。明确报告调试集与独立测试集。

完整离线评测逐步覆盖：成功投放、仍持果、抓空、盘外掉落、遮挡、重试、调整、重复事件、不同目标与提前结束。
加入时间逐步到达的回放，禁止使用未来真实帧或离线未来插值裁剪作为在线输入。
