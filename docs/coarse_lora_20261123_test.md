## 测试协议及边界

- 模型：本地Qwen3-VL-4B-Instruct + coarse_lora_20261123_v1/best（epoch3，按验证loss选定）。
- 151 train、21 val、12 historical_test、20 blind_test的冻结划分不变；本轮测试不回流训练或验证。源ID和头部视频SHA均无训练/验证交集。
- 32条测试的侧文件SHA与冻结lock一致；头部视频SHA与标注绑定的视频一致，FPS与帧数全部一致。缺失镜像视频使用标注指向的原始导入文件，并验证SHA。
- 输入完整原始头部cam0视频及同一训练提示词（包含总时长）；模型原生视频处理器内部2fps采样，不输入答案、已有边界或采摘计数。
- 原始三路没有拼接，本轮不使用第四路头部局部图；不据此声称三路/四路或在线性能。
- 全部测试仍是拿起→采摘→调整→采摘→放回，不覆盖缺段、重复调整或顺序改变。
- 误差基于现有粗标注，未新增逐帧人工真值。两位小数只是输出格式，不代表0.01秒识别精度。
- LoRA模型generate阶段耗时中位数约4.01秒，包含视频token的模型前向与回答生成，不包含视频解码、采样和预处理；完整视频离线测试不等于实时阶段判断或切换延迟。
- 这次结果不包含摘果计数、在线视觉记忆、自动Prompt切换或机器人动作执行。
