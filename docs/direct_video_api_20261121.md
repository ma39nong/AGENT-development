## 结论

现有Token Plan端点的qwen3.8-max实测支持原始MP4以video_url/Base64输入。4次均HTTP200、stop正常结束、关闭思考，usage明确含video_tokens。客户端没有抽帧、缩放、拼接或分块，也没有强制JSON。服务端如何采样未测量，不能理解为模型逐帧处理全部30fps。

此前客户端抽帧多图不是本次视频接口的必要前置条件。前一轮结果只能评价旧方案，不能据此断言直接完整视频识别不准。
